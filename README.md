# Basic LED Circuit 9V

A simple LED circuit built using a 9V battery, LED, resistor, breadboard, and jumper wires.

## 🔧 Components

- 9V Battery
- LED
- Resistor
- Breadboard
- Jumper Wires

## ⚡ How It Works

The 9V battery supplies power to the circuit. The resistor limits the current flowing through the LED, protecting it from excessive current. When the circuit is connected correctly, the LED lights up.
